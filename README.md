# Student Management System

## Project Summary

The **Student Management System (SMS)** is a web-based application
developed with PHP and MySQL. It is designed to help educational
institutions manage student information and academic activities in one
centralized system, reducing manual paperwork and improving data
accuracy and security.

## Main Features

-   **User Authentication:** Role-based login for administrators,
    teachers, and students.
-   **Student Management:** Add, edit, delete, and view student
    information.
-   **Course Management:** Manage courses, subjects, and class sections.
-   **Attendance Management:** Record and track daily attendance.
-   **Marks & Results:** Enter marks and generate student report cards.
-   **Teacher Management:** Manage teacher profiles and subject
    assignments.
-   **Fee Management:** Track student fee payments and receipts.
-   **Reports & Dashboard:** View student lists, performance reports,
    summaries, and role-specific statistics.

## User Roles

-   **Administrator:** Full access to all modules.
-   **Teacher:** Manage attendance and marks, and view student details.
-   **Student:** View profile, attendance, and results.
-   **Parent (Optional):** View a child's academic progress.

## Technology Stack

-   **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
-   **Backend:** PHP 7.4+
-   **Database:** MySQL
-   **Server:** Apache (XAMPP / WAMP / LAMP)
-   **Version Control:** Git (optional)

## Main Database Tables

  Table          Purpose
  -------------- ---------------------------------
  `users`        User accounts and roles
  `students`     Student information
  `teachers`     Teacher information
  `courses`      Courses and class sections
  `attendance`   Student attendance records
  `marks`        Student marks and exam results
  `fees`         Fee payments and payment status

## Key Objectives

-   Centralize student and academic records.
-   Reduce administrative workload and paperwork.
-   Provide role-based access to information.
-   Improve data accuracy and security.
-   Generate reports for academic and administrative use.
