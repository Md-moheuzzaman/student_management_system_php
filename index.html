What it manages

Each module covers one part of school administration, so it can be built and tested on its own.

User authentication
Login and logout with role-based access. Passwords are stored with password_hash().
Student management
Add, edit, delete and view students. Search by name, class or ID, and open a profile with attendance, marks and fee status.
Courses and classes
Create courses, subjects and class sections, and link students to their classes.
Teacher management
Keep teacher profiles and assign each teacher to subjects and classes.
Attendance
Teachers record Present, Absent or Late each day. Students see their own record, percentage and monthly summary.
Marks and results
Enter marks by subject and exam type, calculate totals and grades automatically, and print report cards.
Fee management
Record payments with amount and date, show paid and pending fees, and print receipts.
Reports and dashboard
Role-specific dashboards, student lists, performance and attendance reports, fee collection and pending fee reports.

Who uses it

Every account has one role, and the role decides which pages and data it can reach.

Administrator

Full access to every module.

  • Manage students, teachers, courses, subjects and classes
  • Record fees and print receipts
  • View fee collection, performance and attendance reports

Teacher

Works with the subjects and classes assigned to them.

  • Record daily attendance
  • Enter marks for tests, midterms and finals
  • View student details

Student

Sees their own records only.

  • View profile and attendance percentage
  • View results and report card
  • Check fee status

Parent (optional)

Follows a child's academic progress.

  • View the child's attendance and marks
  • View fee status

Database

Ten InnoDB tables in the student_management_system database, created by the included SQL script.

People and access

  • usersUsername, hashed password, role (admin, teacher, student, parent)
  • studentsProfile, date of birth, address and class
  • teachersProfile, phone and qualification

Academic structure

  • coursesCourse name and description
  • classesClass name and section within a course
  • subjectsSubjects belonging to a course
  • teacher_subjectsWhich teacher teaches which subject in which class

Records

  • attendancePresent, Absent or Late per student, subject and date
  • marksMarks per student, subject and exam type
  • feesAmount, payment date, status and receipt number

Students and teachers link to a user account, and students belong to a class. Attendance, marks and fees link back to the student. All foreign keys use ON DELETE RESTRICT, so a record that is still in use cannot be deleted by accident.

Run it on your computer

  1. Copy the projectPut the project folder inside the XAMPP htdocs folder.
  2. Start the serversOpen the XAMPP Control Panel and start Apache and MySQL.
  3. Import the databaseOpen http://localhost/phpmyadmin, choose Import and select student_management_system.sql. The script creates the database and all ten tables.
  4. Open the appGo to http://localhost/your-folder-name/ and log in.
